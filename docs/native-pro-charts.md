# Native Pro 图表

| 编号 | 组件 | 能力 |
| --- | --- | --- |
| 240 | `SNativeAreaChart` | 多系列、堆叠、区间带。 |
| 241 | `SNativeBarChart` | 横向与纵向、分组与堆叠。 |
| 242 | `SNativeComposedChart` | 面积、柱和线的组合，支持双坐标轴。 |
| 243 | `SNativeLineChart` | 多序列、缺失值、点标记和检查。 |
| 244 | `SNativeLiveChart` | 时间窗口、样本上限、暂停和重连状态。 |
| 245 | `SNativePieChart` | 扇区、圆心、内径和同心环。 |
| 246 | `SNativeRadarChart` | 多维度、刻度、网格和系列比较。 |
| 247 | `SNativeRadialChart` | 径向量值、起止角、轨道和范围。 |
| 248 | `SNativeStackedMeter` | 分段比例、总量上限和明细。 |

Web 和 Native 共用图形计算。Native 通过内嵌 SVG 绘制图形，标题、图例、明细与数值读数由原生视图提供，图形绘制无需联网。触碰图面可检查对应数据，也可通过文字入口查看数据。[组件截图与验收](https://kb.syntrofic.com/?id=20261120170405-zcmv5nc)
