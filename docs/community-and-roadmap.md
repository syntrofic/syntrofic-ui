# 路线图与社区

项目评审从 [组件截图与验收](https://kb.syntrofic.com/?id=20261120170405-zcmv5nc) 开始。每个编号关联可运行的工作台示例，回报问题时注明编号。

| 阶段 | 验收内容 |
| --- | --- |
| M2–M4 | Token、Web 和 Native 组件、空态、键盘与触控 |
| M5–M7 | 高阶组件、应用模板、主题和授权分发 |
| M8 | Agent UI、工具审批、知识来源及界面生成 |
| M9 | 生产力工作台、数据连接、Remote MCP 和移动协作 |
| 发布验收 | 设计逐项复核、实机辅助技术和第三方账号联调 |

## 作品展示

运行 `pnpm dev` 后查看工作台的 `?platform=T-W1` 仪表盘、`?platform=T-W3` 消息、`?platform=T-W5` 财务和 `?platform=S-01` 生产力工作台。Native 验收应用含钱包、活动工作台和移动客服收件箱。

## 企业接入

[工作台接入说明](productivity-workspace.md) 包含 OAuth 身份提供方、成员映射、工具范围和审计路径。企业工作区使用预注册客户端，接入方维护组织成员资格。支持和定制接入通过 [贡献指南](../CONTRIBUTING.md) 的工作区支持入口受理。发布内容以 [更新记录](../CHANGELOG.md) 为准。现有仓库与工作台依照工作区权限可见。
