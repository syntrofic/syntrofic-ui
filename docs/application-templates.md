# 应用模板

| 编号 | 模板 | 可运行流程 |
| --- | --- | --- |
| 360 | Dashboard | 概览、订单、物流跟踪、设置与帮助。 |
| 361 | Mail | 邮件文件夹、打开线程、撰写、保存草稿和模拟发送。 |
| 362 | Chat | 切换会话、流式回复、停止、资料库与探索。 |
| 363 | CRM | 商机筛选、推进阶段、账户健康和公司详情。 |
| 364 | Finances | 资产概览、支出、月份筛选、交易与空状态。 |
| 365 | 模拟钱包 | 组合行情、数据检查、资产详情、交易筛选与模拟收发。 |
| 366 | 健身工作台 | 活动环、计划、记录训练组数、完成及训练历史。 |

Web 模板通过 `SWorkspaceTemplate` 的 `kind` 属性选择。Native 模板使用 `SNativeWorkspaceTemplate`，可在 Android 预览工作台底部打开。模板数据用于本地试用，发送、投资与支付流程使用模拟记录。
