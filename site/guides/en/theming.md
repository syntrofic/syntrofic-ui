## Semantic colors

Use semantic tokens from the stylesheet for text, surfaces, focus, and status. Light pages use a white canvas and subtle neutral surfaces. Test status colors with their labels and icons in both light and dark appearance.

## Appearance

Set `data-sy-theme="light"`, `data-sy-theme="dark"`, or `data-sy-theme="system"` on the applicable element. Use `SBrandTheme` to scope Web design settings and `SNativeProvider` to theme a NativeScript-Vue app.

## Overrides

You can customize `--sy-button-radius`, `--sy-radius-field`, and `--sy-radius-code` independently. Theme motion settings can follow the system or request reduced motion in a subtree.

## Try it

Use the [Theme lab](/themes/) to preview colors, component states, and radius before copying CSS tokens. Use the [CLI and MCP guide](/docs/tools/) to manage a project theme and export tokens.
