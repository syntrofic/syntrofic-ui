## 0.1.0 开发预览

- Vue 与 Native 组件共用一套默认配色。浅色主题使用白色页面底色与低饱和色块。
- Web 复选框的勾和半选横线保持居中。按钮默认全圆角，输入框、代码块与代码栏复制按钮分别采用 9、14 和 12 px。[标准设计](/docs/standard-design/)
- 官网正文、模板和大块预览直接在白底上呈现。设计规范提供 Markdown、CLI 和 AI 工作说明入口。[设计规范](/docs/design-rules/)
- Web 组件目录包含基础控件、高阶集合、图表和对话界面，并提供独立交互示例。
- Native 预览包含 iOS 和 Android 构建入口。Android 使用随包字体，并修正了小号按钮字号和控件垂直居中。
- 品牌主题、应用模板、Agent UI 和开发工具可独立试用。
